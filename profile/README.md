## What we've shipped

### [Utilix](https://utilix.tech) — developer and agent tooling

A single tool registry exposed across six surfaces: browser, Node SDK, Python SDK,
MCP server, REST API and embeddable widgets. Every tool is specified once and behaves
identically everywhere. Deterministic core, no LLM calls, no side effects.

`640` Node functions · `494` Python functions · MCP server for Claude, Cursor and VS Code

→ [utilix.tech](https://utilix.tech) · [github.com/utilix-tech](https://github.com/utilix-tech)

### [Karyfy](https://karyfy.com) — the AI workspace for job search

Six integrated systems covering discovery through offer: resume parsing into a
structured profile, ranked job discovery, per-role tailored applications, interview
prep built from your own experience, career planning with skills-gap analysis, and
salary intelligence.

`FastAPI` · `React` · `PostgreSQL` · `OpenSearch` · `Kubernetes`

→ [karyfy.com](https://karyfy.com) · [github.com/Karyfy](https://github.com/Karyfy)

### [PaperTrade Arena](https://papertrade-arena.vercel.app) — paper trading simulator

Live market data and a categorised news pipeline feeding a full trading terminal:
order types, portfolio P&L, screener, heatmap, earnings and economic calendars,
unusual options flow. Plus multiplayer competitions, leaderboards, XP progression
and structured lessons. Paper trading only — not a brokerage.

→ [papertrade-arena.vercel.app](https://papertrade-arena.vercel.app)
